Giver, Taker, Balanced (giving_pattern)

Describes a partner's behavior - whether their wallet trends up (Giver), stays roughly even (Balanced, the default for most partners), or trends down (Taker). Only meaningful when an account's status is Active. See SOP Section 11 and the full Segmentation Framework.

Status (Applicant / Active / At-Risk / Dormant / Frozen / Exited)

Describes what a partner's account can actually do on the platform - a completely different, deliberately non-overlapping concept from giving_pattern above. Full definitions in the Data Dictionary.

The 9% facilitation fee

One consistent principle applied to every value transfer between partners - whether that's a 999-credit lead-share reward or the 10% deal-closure entitlement. Same rate, same logic, two different bases.

Status pill colours

The colour is only half the information - always read the text next to it too. Two sections can both show the amber "Draft" colour and still mean very different things: one might read "drafted, all six specified" (fully written, just waiting on a signature), another "drafted, exchange rate source still open" (a specific number could still change). The colour tells you the broad category; the words tell you exactly what's actually still open, if anything.

ColourBroad meaning
ConfirmedSettled, not just Sarthy leadership's word but reflected consistently across the hub
DraftWritten and specific, but still a working assumption pending Sarthy's formal sign-off - the accompanying text says exactly what, if anything, is still unresolved
PendingNot written yet

Lead / Admin / Associate

Lead - the Project Lead (you) - strategy, documentation, Sarthy reporting, spec authorship. Associate - handles calls, data entry, first-line follow-up. Admin - Sarthy's operational role inside the SOP's rules (validates leads, confirms conversions, resolves disputes) - not the same person as "Lead" above, a system role Sarthy's team occupies.

deal_duration and the 12-month proration rule

If an engagement runs longer than 12 months, only what's invoiced in the first 12 months counts toward the referrer's entitlement - not the full multi-year contract value. See SOP Section 20 for the worked example.
