What's missing before this can actually run

Half the measures above have a real data source already. The other half need something built first - most of it small:

  • A contact-date field on the Partner record, to measure time-to-signature
  • A startup-contact log, separate from the existing partner call queue in the Interim Operating System
  • A lightweight recommendations log - even a simple running list would satisfy this for now

Cadence

Monthly, at minimum - matching the existing BRD requirement. Nothing here needs to be real-time; a month-old number is still useful for spotting a trend, which is what this is actually for.
