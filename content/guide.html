Read this page first, before opening any other tab. It explains how to move around this hub, and what to do whenever you or I change something on one page that might affect another.

How to move around

  • The left sidebar is grouped by category - things like "Strategic Planning" or "Evidence & Assessment." Numbers show a rough order, but we often jump between them as work unblocks.
  • Every document in a category is listed and visible underneath it, all the time - nothing needs to be clicked open first.
  • Hover over a category or document name and a short note pops up telling you what's inside, in plain words.
  • Each document has a small colored dot: green means finished and confirmed, amber means drafted but still needs sign-off, grey means it hasn't been written yet.
  • Underlined text inside a document, like this, is a real link - click it and it jumps straight to that document.
  • "Version history," at the bottom of the sidebar, is a running list of changes made to the hub itself.

A limit you should know about

This hub is one file. It does not automatically notice when a change in one document should also change another - nothing in the file itself is smart enough for that. The only thing that keeps everything accurate is a simple habit: whenever a document changes, check the table below to see what else it affects, and fix those too, in the same sitting.

How the Playbook is organized - one rulebook, several supporting documents

Partnership SOP v1.0 is the single operating rulebook - how partners join, stay engaged, get grouped, and get helped when something goes wrong. Sarthy's original Playbook 2.0 - years of their own design work on the credit system, referral flow, and abuse rules - has been fully absorbed into it, section by section. That original document is now retired; nothing about the program lives there anymore that isn't also here. A few things still stay separate on purpose: the Communication Template Library (a toolkit of scripts, not narrative rules), the Journey Map and Segmentation Framework (analysis that feeds the SOP's conclusions, not the SOP itself), and the technical documents (a different audience entirely). Sarthy's much older Playbook 1.0 stays out too, but only because there's very little in it beyond what's already captured in the Current-State Assessment's history section.

What I'll do without being asked

  • Every time we update something in the left column of the table above, I will look at what's in the right column and either fix it or tell you clearly that nothing needed to change - not just move on silently.
  • Every bigger change gets a note in Version History, so there's always a record even without proper version control software.
  • If we find a connection between documents that isn't in this table yet, I'll add it, so the table keeps matching reality.

What you and your Associate should do

  • If either of you changes a document without asking me first, tell me about it next time we talk - this table is only useful if it reflects what actually happened.
  • If you see an amber or grey dot on a document, treat it as a reminder that something else in the hub might be waiting on it - not just "still pending."
